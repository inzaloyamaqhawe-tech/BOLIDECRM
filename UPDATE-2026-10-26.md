## Result

The New deal form is now a company workspace. A user enters the company and contact once, then adds Energy, Secure, Connect, Water or SaaS solution tabs. Each completed solution is saved as its own linked deal card in one database transaction. If any card is invalid, none of the cards are partly saved and the entered draft remains available for correction.

Existing deal cards now save changed contacts, phone numbers, email addresses, commercial values and solution-specific details. Refreshing or accidentally closing an edited form no longer discards its local draft. When two users change the same field, the second user sees the latest saved value and their entered value and must choose which one to keep. Changes to different fields are combined automatically.

Repeated submission after an uncertain network response is safe: the same company workspace request returns the already-created deal IDs rather than creating duplicate cards. New opportunities are still checked case-insensitively by company, solution and location. Assigning a deal owner remains explicit; the logged-in developer is not assigned automatically.
